# Taskora — Student Task Manager

## About the Project
Taskora is a simple task-management web application built using Python and Django. It helps students organize their daily tasks.

## Features
- Add tasks with titles and descriptions
- View saved tasks
- Mark tasks as completed or pending
- Delete tasks
- Manage tasks through Django Admin

## Technologies Used
- Python
- Django
- HTML and CSS
- SQLite

## Installation and Setup
1. Clone or download this repository.
2. Create and activate a Python virtual environment:
   ```powershell
   python -m venv venv
   .\venv\Scripts\activate
 3. Install dependencies using pip install , -r requirements.txt 
 4. Run python manage.py migrate.
 5. Start the server using python manage.py runserver.
 6. Open http://127.0.0.1:8000/ in your browser.
